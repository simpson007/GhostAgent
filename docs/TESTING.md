## 复现浏览器测试（可选）

主项目运行不依赖 Playwright。浏览器验收脚本需要环境中已有 `playwright` 包与 Chrome。

先启动 `npm start`，另开终端：

```bash
# 如果 playwright 可直接从当前环境解析
npm run test:browser

# 或通过环境变量指定已有 Playwright 模块入口
PLAYWRIGHT_MODULE=/你的路径/playwright/index.mjs npm run test:browser
```

可设置 `BASE_URL`（默认 `http://127.0.0.1:4173`）与 `BROWSER_CHANNEL`（默认 `chrome`）。脚本在独立浏览器上下文内操作，不影响日常浏览器数据。截图写入 docs，下载文件与报告写入已忽略的 test-results。
