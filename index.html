A SMALL GUIDE TO GET STARTED

小工具，小说明.

不需要复杂配置，从一个能运行的小版本开始。

01

先试用，再扩展

选择一个示例或描述你的项目。点击「让想法显形」，在需求、设计、任务、代码和预览之间切换。下载的 ZIP 包包含完整规格与单文件原型。

预览使用隔离沙箱；下载后通过本地 HTTP 服务运行原型，即可使用浏览器本地存储。

02

模板模式与 AI 模式

GitHub Pages 使用本地规则和预置代码模板，不是实时大模型。支持待办、便签、习惯三个可运行原型；其他想法会生成通用清单，并标注待实现部分。

可选 AI 模式：复制 .env.example 为 .env，在服务器填写兼容 OpenAI 的接口参数，然后运行 npm start。密钥仅在服务器使用。

03

和 Kiro 一起继续构建

下载包中包含 .kiro/specs/ 下的需求、设计、任务文档，以及 steering 规则。在 Kiro 中打开解压目录，先审阅规格，再让 Kiro 实现任务清单。

这些是供 Kiro 使用的文件，不代表网页正在调用 Kiro，也不代表已实际使用 Kiro 完成开发。参赛时请记录真实的 Kiro 操作过程。

04

部署与隐私

网页可直接部署 GitHub Pages，无构建、无依赖。项目历史最多保存 8 条，使用「我的项目」清空记录。输入不做统计、不上报。

模板模式全部本地处理；启用 AI 后，你的输入会发往你配置的模型服务。不要输入敏感资料。浏览器无痕模式或清理站点数据会移除历史。
