# GhostAgent · Product

GhostAgent is a lightweight spec-first workbench for beginner web projects.

- Keep the first version small: one idea form, three spec documents, one working starter.
- The default is a fully local deterministic template mode. Do not call it live AI.
- Optional AI refines a plan through the local server; runnable code still comes from local templates.
- Supported starter types: todo list, notes, and daily habits. Other ideas get an explicitly labelled generic list.
- Do not claim authentication, cloud storage, arbitrary full-stack generation, or actual Kiro usage unless implemented or observed.
- Users must be able to preview a starter and download a ZIP including .kiro specifications.
- UI language: Simplified Chinese, with restrained English labels.
- Never introduce a dependency for a task that is already simple with browser or Node built-ins.
